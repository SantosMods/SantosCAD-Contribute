## Resource Details {.tabset}

### Overview

ND_Ambulance provides medical and ambulance job systems.

Features include:

* Stretcher system
* Injury system
* Defibrillator
* CPR
* Medical bags
* Treatment items
* Player carrying
* Hospital system
* Death screens

### Treatment Items

The project includes treatment support for items such as:

* `gauze`
* `burndresing`
* `splint`
* `tourniquet`

The repository also provides inventory definitions for the stretcher and defibrillator.

### Framework Support

ND_Ambulance is an ND Framework ambulance resource.

Official release notes for `v2.5.3` added ESX and QB compatibility through the resource bridge.

---

## Configuration

Ambulance vehicles can be changed in:

```text
data/vehicles
```

The default configuration references two ambulance vehicles from the MRSA Pack.

Review the included inventory definitions before adding the medical items to your inventory resource.
