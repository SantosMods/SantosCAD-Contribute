## Resource Details {.tabset}

### Overview

ND_Fuel provides vehicle refueling and fuel consumption systems.

Features documented by the project include:

* Fuel nozzle and hose
* Fuel pump UI
* Configurable fuel consumption
* Jerry Can purchasing
* Jerry Can refilling

The official README does not list framework or resource dependencies.

## Features

### Fuel Pumps

ND_Fuel provides a fuel pump interface together with a nozzle and hose system.

### Fuel Consumption

Vehicle fuel consumption can be customized.

### Jerry Can

Players can purchase and refill a Jerry Can through the fuel system.
